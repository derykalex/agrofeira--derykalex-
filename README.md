🌱 AgroFeira - Paragominas

Do produtor para a sua mesa. Conectando o campo à cidade e valorizando a agricultura familiar de Paragominas/PA.

O AgroFeira é uma plataforma web desenvolvida para aproximar consumidores de produtores locais, agricultores familiares e artesãos da região de Paragominas, facilitando a divulgação de produtos frescos, orgânicos e artesanais, além de informar sobre feiras presenciais.

🚀 Funcionalidades da Aplicação

Início / Apresentação: Seção de destaque com informações rápidas sobre a agricultura familiar e acesso direto ao catálogo ou à próxima feira.

Catálogo de Produtos: Pesquisa e filtragem por categorias (Hortaliças, Frutas, Raízes, Mel, Laticínios e Artesanato) com detalhes de preços, unidades e acesso rápido via WhatsApp.

Nossos Produtores: Perfis detalhados de produtores locais (como João da Silva, Apiário do Sol e Artes da Terra), avaliações e localização de barracas.

Próxima Feira: Informações detalhadas sobre data, horário e localização da próxima feira presencial (Praça Matriz, Centro), integrada com mapa interativo.

Como Funciona: Guia passo a passo simples para compradores e produtores.

Contato e Cadastro: Canal direto para dúvidas, sugestões e um formulário para novos produtores se cadastrarem e enviarem seus dados via WhatsApp.

🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias web fundamentais:

HTML5: Estruturação semântica das páginas.

CSS3 / Estilização: Layout moderno, responsivo e amigável com paleta de cores voltada para o setor agrícola.

JavaScript: Interatividade para filtros, listagem de produtos e navegação dinâmica.

GitHub Pages: Hospedagem e publicação do site.
